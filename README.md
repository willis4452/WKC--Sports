# WKC Arbitrage Sports Betting App

This is a full-stack arbitrage sports betting platform using:

- 🔐 Clerk for authentication
- 📦 Supabase for strategy storage
- ⚛️ React frontend (fully responsive)
- 📈 Live strategy simulation and bankroll growth tools

## 📦 Getting Started

1. Clone the repo
2. Create a `.env` file (see `.env.example`)
3. Run:

```bash
npm install
npm run dev
```

## 🚀 Deploy with Vercel

1. Connect your GitHub repo to [https://vercel.com](https://vercel.com)
2. Add the following environment variables:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `VITE_CLERK_PUBLISHABLE_KEY`

3. Click **Deploy**
